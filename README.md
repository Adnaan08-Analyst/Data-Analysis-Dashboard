# Bank-Analysis( Interactive dashboard creation using Excel, SQL, Power bi , Tableau )
## Project Objective
To perform end-to-end loan data analysis using Excel, SQL, Power BI, and Tableau, enabling data-driven insights into loan trends, borrower patterns, and financial performance.

## Dataset used
- <a href="https://github.com/Adnaan08-Analyst/Data-Analysis-Dashboard/blob/main/bankcombined.xlsx">Dataset</a>

## Questions
- What is the total loan amount issued each year?
- Which loan grades and subgrades have the highest revolving balance?
- What percentage of loans are verified vs. non-verified?
- Which states have the highest and lowest loan counts?
- What is the repayment status distribution across states?
- How does home ownership type affect last payment status?
- What is the default or charged-off rate across different borrower groups?
- Which year shows the highest increase in loan issuance?
- How does borrower verification impact total payment received?
- Which borrower segments show the strongest repayment behavior?

- Dashboard KPI<a href="https://github.com/Adnaan08-Analyst/Data-Analysis-Dashboard/blob/main/Bank%20analytics%20dashboard.png">View Dashboard</a>

## Prcosess 
- Data Collection – Imported Finance_1 and Finance_2 loan datasets for analysis.
- Data Cleaning – Removed unwanted columns, fixed date formats, and handled null values.
- Data Transformation – Standardized fields and prepared tables for analysis in Excel and SQL.
- Exploratory Analysis – Identified loan trends, borrower patterns, and verification insights.
- KPI Design – Defined key metrics such as yearly loan amounts, grade-wise balance, and state-wise loan status.
- Dashboard Creation – Built interactive dashboards using Excel, Power BI, and Tableau.
- SQL Querying – Executed queries for filtering, grouping, and validating insights.
- Visualization & Insights – Highlighted patterns in loan growth, verification, home ownership, and repayment behavior.
- Conclusion & Documentation – Summarized insights and documented the complete end-to-end workflow.
