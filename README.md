# Bank-Analysis( Interactive dashboard creation using Excel, SQL, Power bi , Tableau )
## Project Objective
To perform end-to-end loan data analysis using Excel, SQL, Power BI, and Tableau, enabling data-driven insights into loan trends, borrower patterns, and financial performance.

## Dataset used
- <a href="https://github.com/Adnaan08-Analyst/Data-Analysis-Dashboard/blob/main/bankcombined.xlsx">Dataset</a>

## Questions
- What is the total loan amount issued each year?
- Which loan grades and subgrades have the highest revolving balance?
- What percentage of loans are verified vs. non-verified?
- Which states have the highest and lowest loan counts?
- What is the repayment status distribution across states?
- How does home ownership type affect last payment status?
- What is the default or charged-off rate across different borrower groups?
- Which year shows the highest increase in loan issuance?
- How does borrower verification impact total payment received?
- Which borrower segments show the strongest repayment behavior?

## Project Insights
- Loan Growth Trend: Loan amounts increased steadily from 2007–2009, with a sharp rise in 2010–2011, indicating rapid expansion in loan issuance.
- Grade & Subgrade Performance: Borrowers in Grade A and B show the highest revolving balances, while Grade F and G have the lowest, highlighting differences in credit quality.
- Verification Status: Majority of loans are verified, but around 40% remain unverified, showing a need for stronger validation processes.
- State-wise Loan Patterns: California, New York, and Texas have the highest loan volumes. Most states show strong repayment trends with a high number of fully paid loans.
- Risk Zones: States like Texas and New Jersey show higher counts of current and charged-off loans, indicating repayment risks.
- Home Ownership Effect: Renters form the largest group of borrowers, while mortgage holders show strong long-term financial commitments that impact repayment timelines.
- Borrower Behavior Insights: Verified borrowers tend to show better repayment performance compared to non-verified ones.
- Dashboard Findings: Visual dashboards across Power BI, Tableau, and Excel helped reveal patterns in loan distribution, repayment behavior, and borrower profiles.

## Final Conclusion 
The loan analysis using Excel, SQL, Power BI, and Tableau uncovered clear trends in loan growth, borrower behavior, verification gaps, and state-wise performance. Insights highlight strong repayment patterns overall while revealing risk areas, supporting better decision-making for financial monitoring and lending strategies.
